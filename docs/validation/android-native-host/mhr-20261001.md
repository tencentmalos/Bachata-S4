## Dynamic resource failure (01:27 onward, ongoing)

DMA is confirmed applied by the Android service. The previous loop-offset error is bypassed only for ordinary GPU constant reads; it is **not** a complete dynamic descriptor implementation. Several fragment shaders still report unflattened descriptor sources. Compute `cs 0xbb6a1810` then fails with resource word 0 from `ReadLane`.
