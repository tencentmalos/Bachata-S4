Making this title playable requires a separate Android compatibility change across the actual startup dependency chain, followed by input, rendering, level and save checks. Follow the repository's whole-family policy: audit the complete inventory and desktop behavior, including guest pointers, callbacks, signal/context state and teardown; do not patch only the first NID and call the game accepted. Preserve real offline/unavailable semantics for NP functions.
