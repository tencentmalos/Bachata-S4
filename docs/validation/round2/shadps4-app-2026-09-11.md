## 已交付(可编译、可安装、可运行到 Library)

- 整树复刻 `references/Bachata-S4-android/android/BachataS4`(13 模块,Compose/Hilt/Room/nav,约 20K 行 Kotlin),

- 工具链降级到 A0 已验证组合:AGP 8.13.2 / Kotlin 2.0.20 / Gradle 8.13 / compileSdk36 / minSdk33 / targetSdk35 /

  KSP 2.0.20-1.0.25。每模块显式加 kotlin-android 插件;去掉空 build-logic;version catalog 保留。
- ManagedSession 接缝从"外部进程 + BACHATA/1 socket"改接**进程内 `guest_cpu_fex`**:
  - `core/runtime/src/main/cpp/fex_session_jni.cpp`(A0 validation_jni 的有状态变体):进程级 session
    (address space + context + owner 线程),`nativeStart/nativeRequestStop/nativeIsRunning/nativeLastStopReason/
    nativeLastError/nativeIdentity`;有界 x86-64 递减循环 fixture,Stop 走 `RequestInterrupt(Cancel)+WaitStopped`。
  - `NativeFexSession.kt`(JNI 桥)+ `FexSessionService.kt`(app,ManagedSession 指向它)。
  - 新 `cpp/CMakeLists.txt` 只 build `libshadps4_fex_session.so`(add_subdirectory cmake/fex、link guest_cpu_fex、
    include src、-fexceptions);丢 winlator/vortek/adrenotools;pkg native 暂缓(需 externals/libdeflate,主仓未 vendor)。
- drivers/settings/session 去 `runtime.process.Vulkan*` 依赖:后端无关的 `RuntimeVulkanDriver/Ids/Preference`
  提到 `runtime.driver` 包,`VulkanDriverConfiguration` 去 Box64Mode 精简,glibc/vortek 分支抛 UnsupportedOperation;
  settings 剪 box64(保留 box64.json 设置目录数据,FEX 下惰性)。
- app 去掉 `verifyNativeRuntimeFixes` 原生修复门(它检查已丢弃的 vortek/winlator 标记)。
- setup/routing:FEX 后端编进 APK,无 glibc runtime 可装 → `MainActivity` 直接进 Library、`SetupViewModel` 默认 ready。
  app label → "shadPS4 FEX"。

## 架构缺口(NOT_RUN,不得据本次宣称可跑游戏)

真正跑真实游戏需要**把主仓 shadPS4 core 迁到 Android/bionic 原生构建 + JNI + Vulkan Surface**(主仓 `src/core/CMakeLists.txt`
无 ANDROID 分支,整 core 从未原生构建;Android 上只验证过 `src/core/guest_cpu`/FEXCore)。参考工程是靠**外部 glibc
shadPS4 子进程 + Box64/loader + Winlator X + Vortek** 套壳"看起来完整",主仓架构约束 #1 拒绝该路线。因此:

- **session 屏 = UI 壳 + FEX 冒烟**:接进程内 `guest_cpu_fex` 跑有界 x86-64 fixture,证明 CPU 后端在 app 进程里活着,
  **不是游戏**。A0 test APK 已证同后端在本机执行(45/45)。
- session 的端到端 FEX 冒烟运行**尚未上机触发**:FexSessionService 是 `exported=false`(adb 无法直接拉起),
  经 UI 触发需 library 里有游戏,而 `.pkg` 导入的 native 提取(bachata_pkg)暂缓(需 externals/libdeflate)。
  下一步:vendor libdeflate 接回 pkg native,或加 test-only 无游戏冒烟入口,再上机取 10 次 start/stop/restart 记录。
- 其它 NOT_RUN:真实 PS4 HLE/Orbis、host→guest 调用(HleScope/InvokeGuest)、Vulkan 输出(SurfaceView 占位)、
  controller→guest(sink 为 stub)、Turnip 被 renderer 加载(仅安装)、设置影响冒烟运行、Swan API36 终验。

## 复现
```
cd android/shadps4-app   # local.properties: sdk.dir + fexBuildDir=<repo>/build/fexcore-android
JAVA_HOME=<jdk17> ~/.gradle/wrapper/dists/gradle-8.13-bin/*/gradle-8.13/bin/gradle \
  :app:assembleFdroidDebug -Dhttp(s).proxyHost/Port=...   # 依赖首次需代理(本机 Clash GUI 127.0.0.1:7897)
adb install -r app/build/outputs/apk/fdroid/debug/app-fdroid-debug.apk
adb shell am start -n com.shadps4.android/.MainActivity
```
